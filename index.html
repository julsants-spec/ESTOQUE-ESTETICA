Sincronização na nuvem

Faça isto uma vez (é gratuito). Depois, o mesmo estoque aparece no notebook e no celular.

  1. Em console.firebase.google.com, crie um projeto (pode desligar o Google Analytics).
  2. Build › Authentication › Começar › aba “Método de login” › ative E-mail/senha.
  3. Build › Firestore Database › Criar banco de dados (modo produção). Na aba Regras, cole o texto abaixo e clique em Publicar:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /usuarios/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

Entre com o mesmo e-mail e senha no notebook e no celular. Se for a primeira vez, clique em “Criar conta”.

Tudo que você cadastrar, editar ou excluir aqui aparece nos outros aparelhos conectados. Sem internet, o app continua funcionando e sincroniza quando a conexão voltar.
